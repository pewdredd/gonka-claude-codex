# Claude Code и Codex на GonkaGate

Готовая папка, которая подключает модели [GonkaGate](https://gonkagate.com) (GLM, DeepSeek,
MiniMax) к Claude Code и Codex:

- **Claude Code с подпиской**: в `/model` остаются все модели Claude, а GLM-5.3 Flash
  добавляется к ним ещё одной строкой. Переключаешься между ними как обычно.
- **Claude Code без подписки**: все запросы идут в GLM, подписка не нужна.
- **Codex**: работает на GLM, DeepSeek или MiniMax вместо GPT.

Работает только из этой папки. В любой другой папке `claude` и `codex` остаются обычными,
твоя подписка и настройки не трогаются.

## Что нужно

- [Claude Code](https://docs.claude.com/en/docs/claude-code/setup) и/или
  [Codex CLI](https://developers.openai.com/codex/cli)
- Python 3.8+. Проверка: `python --version` (на Mac - `python3 --version`).
  Нет на Windows - `winget install Python.Python.3.12`, потом перезапусти терминал
- Ключ GonkaGate `gp-...` из личного кабинета gonkagate.com

## Подготовка

1. Скачай папку: `git clone https://github.com/pewdredd/gonka-claude-codex` или зелёная кнопка
   Code → Download ZIP и распаковать.
2. Скопируй `.env.example` в `.env` и впиши свой ключ: `GONKA_API_KEY=gp-...`.
   Забудешь - `.env` создастся сам при первом запуске, останется вписать ключ.

## Claude Code с подпиской: GLM пятой моделью

Открой терминал в этой папке и набери:

```
claude
```

Claude спросит, доверяешь ли ты папке - ответь «да». Без этого не запустится прокси.

Дальше `/model`: там твои обычные модели Claude и последней строкой **GLM-5.3 Flash**.
Выбрал - пошло через GonkaGate, вернулся на Opus или Sonnet - снова подписка.

Вместо GLM можно добавить DeepSeek или MiniMax: поменяй `ANTHROPIC_CUSTOM_MODEL_OPTION`
и `ANTHROPIC_CUSTOM_MODEL_OPTION_NAME` в `.claude/settings.json`. Строка в списке одна, но
любую модель GonkaGate можно включить и без неё, прямо по id:

```
/model deepseek-ai/deepseek-v4-flash-0731
/model minimaxai/minimax-m2.7
```

Claude Code при выборе этих моделей пишет, что не знает их и считает контекст в 200k токенов.
Это нормально: у GLM и DeepSeek контекст 400k, просто сжатие диалога начнётся раньше.

## Claude Code без подписки: всё на GLM

```
claude --settings .claude/gonka-only.json
```

Все модели в `/model`, включая фоновые запросы и субагентов, подменяются на GLM.
Подписка и вход в аккаунт Anthropic не нужны.

## Codex

Windows (PowerShell или cmd), в этой папке:

```
.\codex-gonka.cmd
```

Mac и Linux:

```
./codex-gonka.sh
```

Скрипт поднимает прокси, кладёт профиль `~/.codex/gonka.config.toml` и запускает
`codex --profile gonka`. Общий `~/.codex/config.toml` не трогается, обычный `codex`
остаётся на GPT. Все аргументы передаются в Codex как есть:

```
.\codex-gonka.cmd -m deepseek-ai/deepseek-v4-flash-0731
.\codex-gonka.cmd exec "перескажи README.md"
```

Модели: `zai-org/glm-5.3-flash` (по умолчанию), `deepseek-ai/deepseek-v4-flash-0731`,
`minimaxai/minimax-m2.7`. Вход в аккаунт OpenAI не нужен.

Почему не просто `codex` в папке, как с Claude: Codex не разрешает задавать провайдера
моделей из папки проекта, только из своей домашней папки `~/.codex`.

## Как это устроено

Напрямую ни Claude Code, ни Codex с GonkaGate не работают. Между ними стоит маленький
прокси `proxy.py` (только стандартная библиотека Python, ставить ничего не надо).
Он подставляет ключ из `.env` и делает три вещи:

- **Делит запросы Claude Code.** Модель со слэшем в id (`zai-org/...`, `deepseek-ai/...`,
  `minimaxai/...`) уходит в GonkaGate, модель Claude - в Anthropic как есть, с твоей
  авторизацией. Ключ GonkaGate в Anthropic не уходит, подписка в GonkaGate - тоже.
- **Чинит запросы для шлюза.** GonkaGate отклоняет запросы Claude Code с ошибкой 400:
  не принимает сообщения с ролью system и regex с lookahead в схемах инструментов.
  Прокси их переписывает.
- **Переводит Codex.** Codex говорит только на OpenAI Responses API, а GonkaGate понимает
  только Chat Completions. Прокси переводит запрос туда, а ответ со стримом и вызовами
  инструментов - обратно.

Файлы:

- `.claude/settings.json` - направляет Claude Code в прокси на `127.0.0.1:8787` и добавляет
  GLM в `/model`. Хук там же поднимает прокси в фоне при каждом старте `claude`.
- `.claude/gonka-only.json` - режим без подписки, подключается через `--settings`.
- `codex-gonka.cmd`, `codex-gonka.sh` - запуск Codex.
- `codex-models.json` - описания моделей GonkaGate для Codex: контекст, инструменты.
  Без него Codex не даёт модели инструмент правки файлов.
- `.env` в git не попадает (см. `.gitignore`), так что ключ не утечёт, даже если
  ты выложишь папку.

## Что работает

Проверено 2026-10-02 на Claude Code 2.1.285 и Codex 0.144.1.

| | Claude Code | Codex |
|---|---|---|
| GLM-5.3 Flash | работает | работает |
| DeepSeek V4 Flash | работает | работает |
| MiniMax M2.7 | работает | работает |
| Модели Claude по подписке рядом с ними | работает | - |
| Чтение и правка файлов, команды в терминале | работает | работает |
| WebSearch (поиск в интернете) | **нет** на моделях GonkaGate - серверный инструмент Anthropic | **нет** |
| Картинки и PDF | **нет** - модель их не видит, прокси подставляет пометку, сессия не ломается | **нет**, так же |

Рассуждения моделей: в Codex показываются отдельным блоком, в Claude Code MiniMax пишет
их прямо в ответ, прокси их вырезает.

Честно: модели GonkaGate слабее Claude и GPT. Иногда в ответ лезет лишний текст на английском
или один и тот же инструмент вызывается дважды. Для простых задач хватает, для сложных - нет.
Зато в режиме с подпиской сложное можно отдать Opus, не выходя из сессии.

## Важно

- **Запускай `claude` в корне этой папки.** Из подпапки Claude Code настройки не подхватывает
  и работает как обычный. Свои проекты клади в подпапки, но `claude` запускай отсюда.
  Codex через `codex-gonka` можно запускать откуда угодно, указав полный путь к скрипту.
- Если ключ забыл или он неправильный - в чате будет ошибка с подсказкой. Поправь `.env`
  и повтори запрос, перезапускать ничего не надо.
- У шлюза лимит одновременных запросов на ключ. Если он занят, прокси ждёт и повторяет
  сам, до двух минут. В это время модель просто думает дольше обычного.
- Прокси после выхода остаётся висеть в фоне и подхватится при следующем запуске.
  Остановить: перезагрузка или завершить процесс `python`/`pythonw` в диспетчере задач.
  После обновления `proxy.py` его надо остановить, иначе продолжит работать старая версия.
- Порт 8787 занят чем-то другим - поменяй его в `.claude/settings.json` (`ANTHROPIC_BASE_URL`)
  и задай такой же через переменную `GONKA_PROXY_PORT`.
