## 💡 Что это и зачем

[GonkaGate](https://gonkagate.com) — шлюз к открытым моделям: **GLM**, **DeepSeek**, **MiniMax**.
Они заметно дешевле Claude и GPT, но Claude Code и Codex напрямую с ними работать не умеют.

Эта папка решает проблему: внутри лежит маленький переводчик (`proxy.py`), который
стоит между твоей программой и GonkaGate и переписывает запросы так, чтобы всё работало.

> [!NOTE]
> Всё работает **только внутри этой папки**. В любой другой папке `claude` и `codex`
> остаются обычными — твоя подписка и настройки не трогаются.

## 🧭 Какой режим выбрать

| Если у тебя… | Выбирай | Что получишь |
|---|---|---|

| Нет подписки Claude | **[Режим 2](#-режим-2-claude-code-без-подписки)** | Claude Code целиком на GLM |

Не уверен? Начни с режима 2 — ему ничего, кроме ключа GonkaGate, не нужно.

## 🚀 Установка за 3 шага

### Шаг 1. Скачай папку

```bash
git clone https://github.com/pewdredd/gonka-claude-codex
cd gonka-claude-codex
```

<details>
<summary>Нет git? Скачай архивом</summary>

На странице репозитория нажми зелёную кнопку **Code → Download ZIP**, распакуй архив
и открой терминал в распакованной папке.

**Как открыть терминал в папке:**
- **Windows** — открой папку в Проводнике, кликни правой кнопкой по пустому месту → «Открыть в терминале».
- **Mac** — правой кнопкой по папке в Finder → «Новый терминал по адресу папки».

</details>

### Шаг 2. Впиши свой ключ

Сделай копию файла `.env.example` с именем `.env`:

```bash
copy .env.example .env    # Windows
cp .env.example .env      # Mac / Linux
```

Открой `.env` в любом редакторе и замени `gp-...` на свой ключ:

```env
GONKA_API_KEY=gp-твой-настоящий-ключ
```

> [!TIP]
> Забыл этот шаг — не страшно. `.env` создастся сам при первом запуске, останется только вписать ключ.

> [!IMPORTANT]
> Файл `.env` никогда не попадает в git (он в `.gitignore`). Ключ не утечёт,
> даже если ты выложишь папку на GitHub.

### Шаг 3. Запусти нужный режим

Выбери один из режимов ниже 👇

## 🟠 Режим 1. Claude Code с подпиской + GLM

**Для кого:** у тебя есть подписка Claude, и ты хочешь иметь под рукой дешёвую модель для простых задач.

**1.** В терминале, открытом в этой папке:

```bash
claude
```

**2.** Claude спросит, доверяешь ли ты этой папке — ответь **«да»**.

> [!WARNING]
> Без «да» прокси не запустится, и GLM работать не будет.

**3.** Набери `/model`. Там будут твои обычные модели Claude и последней строкой — **GLM-5.3 Flash**.

```
  Opus
  Sonnet
  Haiku
❯ GLM-5.3 Flash   ← запросы идут через GonkaGate
```

Выбрал GLM — пошло через GonkaGate. Вернулся на Opus или Sonnet — снова по подписке.
Переключаться можно прямо посреди разговора.

<details>
<summary>Хочу DeepSeek или MiniMax вместо GLM</summary>

Любую модель GonkaGate можно включить по её id:

```
/model deepseek-ai/deepseek-v4-flash-0731
/model minimaxai/minimax-m2.7
```

Чтобы она постоянно висела в списке `/model` вместо GLM, поменяй
`ANTHROPIC_CUSTOM_MODEL_OPTION` и `ANTHROPIC_CUSTOM_MODEL_OPTION_NAME` в `.claude/settings.json`.

Claude Code при выборе таких моделей предупредит, что не знает их, и будет считать
контекст в 200k токенов. Это нормально: у GLM и DeepSeek контекст 400k, просто сжатие
диалога начнётся чуть раньше.

</details>

## 🟢 Режим 2. Claude Code без подписки

**Для кого:** подписки Claude нет, но хочется пользоваться Claude Code.

```bash
claude --settings .claude/gonka-only.json
```

Готово. Все модели в `/model` — включая фоновые запросы и субагентов — подменяются на GLM.
Входить в аккаунт Anthropic не нужно.

## 🟣 Режим 3. Codex

**Для кого:** пользуешься Codex и хочешь работать на моделях GonkaGate вместо GPT.

Запускай из этой папки специальный скрипт (не просто `codex`):

| Система | Команда |
|---|---|
| Windows (PowerShell или cmd) | `.\codex-gonka.cmd` |
| Mac / Linux | `./codex-gonka.sh` |

Скрипт сам поднимет прокси, создаст профиль `~/.codex/gonka.config.toml` и запустит
`codex --profile gonka`. Твой основной `~/.codex/config.toml` не трогается — обычный `codex`
останется на GPT. Вход в аккаунт OpenAI не нужен.

Все аргументы передаются в Codex как есть:

```powershell
.\codex-gonka.cmd -m deepseek-ai/deepseek-v4-flash-0731   # другая модель
.\codex-gonka.cmd exec "перескажи README.md"              # разовая задача
```

**Доступные модели:**

| Модель | id |
|---|---|
| GLM-5.3 Flash *(по умолчанию)* | `zai-org/glm-5.3-flash` |
| DeepSeek V4 Flash | `deepseek-ai/deepseek-v4-flash-0731` |
| MiniMax M2.7 | `minimaxai/minimax-m2.7` |

<details>
<summary>Почему нельзя просто набрать <code>codex</code>, как с Claude?</summary>

Codex не разрешает задавать провайдера моделей из папки проекта — только из своей
домашней папки `~/.codex`. Поэтому нужен скрипт-обёртка.

</details>

## ✅ Что работает, а что нет

Проверено 2026-10-02 на Claude Code 2.1.285 и Codex 0.144.1.

| | Claude Code | Codex |
|---|:---:|:---:|
| GLM-5.3 Flash | ✅ | ✅ |
| DeepSeek V4 Flash | ✅ | ✅ |
| MiniMax M2.7 | ✅ | ✅ |
| Модели Claude по подписке рядом с ними | ✅ | — |
| Чтение и правка файлов, команды в терминале | ✅ | ✅ |
| WebSearch (поиск в интернете) | ❌ | ❌ |
| Картинки и PDF | ❌ | ❌ |

- **WebSearch** — это серверный инструмент Anthropic, на моделях GonkaGate его нет.
- **Картинки и PDF** модель не видит. Прокси подставляет вместо них пометку, так что сессия не ломается.
- **Рассуждения моделей** в Codex показываются отдельным блоком. В Claude Code MiniMax пишет их
  прямо в ответ — прокси их вырезает.

> [!NOTE]
> **Честно о качестве.** Модели GonkaGate слабее Claude и GPT. Иногда в ответ попадает
> лишний текст на английском или один инструмент вызывается дважды. Для простых задач хватает,
> для сложных — нет. Зато в режиме 1 сложное можно отдать Opus, не выходя из сессии.

## 🩺 Частые проблемы

<details>
<summary><b>GLM не появился в <code>/model</code> / Claude работает как обычно</b></summary>

- Убедись, что запускаешь `claude` **в корне этой папки**, а не в подпапке. Из подпапки
  Claude Code настройки не подхватывает. Свои проекты можно класть в подпапки, но `claude`
  запускай отсюда.
- Проверь, что на вопрос о доверии к папке ты ответил «да».

</details>

<details>
<summary><b>Ошибка про ключ</b></summary>

Ключ не вписан или неправильный. Поправь `.env` и просто повтори запрос — перезапускать ничего не нужно.

</details>

<details>
<summary><b>Модель очень долго думает</b></summary>

У шлюза есть лимит одновременных запросов на один ключ. Если он занят, прокси сам ждёт
и повторяет запрос — до двух минут. В это время модель просто «думает» дольше обычного.

</details>

<details>
<summary><b>Обновил <code>proxy.py</code>, а ничего не изменилось</b></summary>

Прокси после выхода остаётся работать в фоне и подхватывается при следующем запуске.
Поэтому после обновления его нужно остановить: перезагрузи компьютер или заверши процесс
`python` / `pythonw` в диспетчере задач (на Mac — в «Мониторинге системы»).

</details>

<details>
<summary><b>Порт 8787 занят другой программой</b></summary>

Поменяй порт в `.claude/settings.json` (параметр `ANTHROPIC_BASE_URL`) и задай такой же
через переменную окружения `GONKA_PROXY_PORT`.

</details>

<details>
<summary><b>Хочу запускать Codex из другой папки</b></summary>

Можно — просто укажи полный путь к скрипту, например `C:\path\to\gonka-claude-codex\codex-gonka.cmd`.

</details>

## ⚙️ Как это устроено внутри

```
┌──────────────┐        ┌────────────────────┐        ┌──────────────┐
│ Claude Code  │ ─────▶ │                    │ ─────▶ │  GonkaGate   │  GLM / DeepSeek / MiniMax
│   или Codex  │        │  proxy.py          │        └──────────────┘
└──────────────┘        │  127.0.0.1:8787    │        ┌──────────────┐
                        │                    │ ─────▶ │  Anthropic   │  модели Claude по подписке
                        └────────────────────┘        └──────────────┘
```

`proxy.py` написан только на стандартной библиотеке Python — ставить ничего не надо.
Он подставляет ключ из `.env` и делает три вещи:

1. **Разводит запросы Claude Code.** Модель со слэшем в id (`zai-org/...`, `deepseek-ai/...`,
   `minimaxai/...`) уходит в GonkaGate, модель Claude — в Anthropic как есть, с твоей
   авторизацией. Ключ GonkaGate в Anthropic не уходит, данные подписки в GonkaGate — тоже.
2. **Чинит запросы для шлюза.** GonkaGate отклоняет запросы Claude Code с ошибкой 400:
   не принимает сообщения с ролью system и regex с lookahead в схемах инструментов.
   Прокси их переписывает.
3. **Переводит для Codex.** Codex говорит только на OpenAI Responses API, а GonkaGate понимает
   только Chat Completions. Прокси переводит запрос туда, а ответ со стримом и вызовами
   инструментов — обратно.

### Что за файлы в папке

| Файл | Зачем |
|---|---|
| `proxy.py` | Сам прокси-переводчик |
| `.env.example` | Шаблон для `.env` с твоим ключом |
| `.claude/settings.json` | Направляет Claude Code в прокси и добавляет GLM в `/model`. Там же хук, который поднимает прокси при каждом старте `claude` |
| `.claude/gonka-only.json` | Настройки режима без подписки (подключается через `--settings`) |
| `codex-gonka.cmd`, `codex-gonka.sh` | Запуск Codex на Windows и Mac/Linux |
| `codex-models.json` | Описания моделей GonkaGate для Codex: контекст, инструменты. Без него Codex не даёт модели править файлы |
